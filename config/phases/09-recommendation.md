## Goal
Design the recommender, or state clearly that the project does not need one.

## Checklist
- What will be recommended
- User-based recommendations
- Item-based recommendations
- Content-based filtering
- Collaborative filtering
- Hybrid recommendations
- User interaction tracking
- Likes / clicks / views / history
- Ranking algorithm
- Similarity calculation
- Cold-start solution
- Trending / popular recommendations
- Personalized recommendations
- Feedback loop
- Recommendation explanation (Recommended because...)
- Diversity
- Duplicate recommendation prevention
- Recommendation evaluation
