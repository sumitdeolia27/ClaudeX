## Goal
Set numeric performance budgets and the techniques that will hit them.

## Checklist
- Page load time
- API response time
- Database query speed
- AI inference speed
- Caching
- CDN
- Compression
- Pagination
- Lazy loading
- Optimized assets
- Database indexes
- Background processing
- Queue system where required
- Memory and CPU usage
- Concurrent-user testing
