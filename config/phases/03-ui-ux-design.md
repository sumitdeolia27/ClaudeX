## Goal
Define the screens, flows, and design system the frontend will implement.

## Checklist
- Wireframes (described screen by screen)
- User flow
- Dashboard layout
- Navigation structure
- Design system
- Fonts, colors, icons
- Buttons, forms, cards, modals
- Mobile / tablet / desktop layouts
- Accessibility contrast
- Keyboard navigation
- Validation messages
- Skeleton / loading UI
- 404 and 500 pages
- Onboarding / tutorial
- Consistent spacing and components
