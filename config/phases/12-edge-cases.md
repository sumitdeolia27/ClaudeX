## Goal
Enumerate failure modes and the exact behaviour the system must show for each.

## Checklist
- Empty input
- Very large input
- Wrong input type
- Duplicate data
- No internet
- Slow internet
- API timeout
- Server unavailable
- Database unavailable
- Expired login / session
- Invalid token
- Unauthorized access
- User refreshes during process
- Multiple simultaneous requests
- File too large
- Unsupported file
- AI unable to predict confidently
- No recommendation available
- Zero search results
