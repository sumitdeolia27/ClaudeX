## Goal
Choose the modelling approach and the evidence that will prove it works.

## Checklist
- Problem type: classification, regression, recommendation, NLP, CV
- Baseline model
- Algorithm selection
- Model architecture
- Training pipeline
- Hyperparameter tuning
- Validation strategy
- Cross-validation where appropriate
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC where relevant
- Confusion matrix
- MAE / MSE / RMSE for regression
- Recommendation metrics: Precision@K / Recall@K / NDCG
- Model comparison
- Overfitting / underfitting checks
- Explainability
- Confidence score
- Model serialization
- Model versioning
- Inference API
- Retraining strategy
- Drift monitoring
