## Goal
Write the actual script and prepared answers for a demo or viva.

## Checklist
- 30-second project introduction
- Problem statement
- Why you selected the problem
- Existing solution
- Your solution
- Architecture
- Tech stack
- Dataset
- Model / algorithm
- Feature demo
- Security
- Testing
- Results
- Limitations
- Future improvements
- Q: Why did you choose this technology?
- Q: What happens if traffic increases?
- Q: How do you secure user data?
- Q: How did you evaluate your model?
- Q: What is unique about your project?
