## Goal
Describe what changes at 10, 1,000, and 100,000 users.

## Checklist
- 10 users to 1,000 to 100,000 users
- Horizontal scaling
- Load balancing
- Database scaling
- Redis / cache
- Message queues
- Microservices only if required
- CDN
- Cloud storage
- Autoscaling
- Stateless backend design where appropriate
