## Goal
Decide what is watched in production and what triggers an alert.

## Checklist

- Error tracking
- Server health
- CPU / RAM monitoring
- API latency
- Database performance
- Failed login monitoring
- Model performance
- User activity
- Uptime monitoring
- Alerts
- Crash reporting
