## Goal
Specify every endpoint with request, response, and status codes.

## Checklist
- Clear endpoint naming
- GET / POST / PUT / PATCH / DELETE
- Request schema
- Response schema
- HTTP status codes
- Authentication
- Authorization
- Validation
- Pagination
- Filtering
- Sorting
- Error response format
- Rate limits
- API documentation using Swagger / OpenAPI
