## Goal
Survey what already exists and state honestly how this project differs. Mark any specific claim that needs verification instead of inventing citations.

## Checklist

- Competitor analysis
- Research papers
- Existing datasets
- Existing APIs
- Similar GitHub projects
- Industry solutions
- Limitations of current solutions
- Why your project is different
