## Goal
Pin down the exact problem, who it is for, and what done means, so every later phase has a fixed target to aim at.

## Checklist
- Exact problem statement the project solves
- Who will use it (primary and secondary audiences)
- Why the project is needed now
- What is wrong with existing solutions
- What the proposed solution improves, concretely
- Functional requirements (login, search, upload, prediction, dashboard, notifications)
- Non-functional requirements (speed, security, scalability, reliability, usability)
- Scope: explicitly in, and explicitly out
- Success criteria / KPIs with numeric targets
- User roles: User, Admin, Moderator, Developer
- User stories and use cases
