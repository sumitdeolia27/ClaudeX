## Goal
Produce a concrete schema with keys, relationships, and indexes.

## Checklist
- SQL or NoSQL selection with reasoning
- Tables / collections
- Schema
- Primary and foreign keys
- Relationships
- Indexing
- Unique constraints
- Validation
- Created / updated timestamps
- Soft delete if required
- Database backup
- Database migration
- Encryption for sensitive data
- Query optimization
