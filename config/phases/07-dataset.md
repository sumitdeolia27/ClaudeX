## Goal
Define where data comes from and every quality gate it must pass. Skip gracefully if the project has no AI/ML component.

## Checklist
- Dataset source
- Dataset size
- Number of classes / categories
- Features / columns
- Labels
- Data format
- Licensing / permission
- Missing values
- Duplicate records
- Corrupted data
- Class imbalance
- Outliers
- Noise
- Data cleaning
- Preprocessing
- Normalization / scaling
- Encoding categorical values
- Feature engineering
- Data augmentation
- Train / validation / test split
- Data leakage checks
- Bias checks
- Dataset versioning
- Dataset documentation / data dictionary
